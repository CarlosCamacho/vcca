# Contributing to VCCA

Thanks for your interest in VCCA.

## Bug reports are welcome

The most helpful thing you can do is report bugs. [Open an issue](https://github.com/CarlosCamacho/vcca/issues/new/choose)
and fill in the form: your VCCA version, your device, and the steps that
lead to the problem. A screenshot, short video or save state makes a bug much
easier to fix.

Please search the [existing issues](https://github.com/CarlosCamacho/vcca/issues)
first, and never attach ROMs or commercial disk images: they're copyrighted.

## Security problems

Report them privately through
[Security → Report a vulnerability](https://github.com/CarlosCamacho/vcca/security/advisories/new),
not in a public issue.

## Code

VCCA doesn't accept pull requests. If you've found a fix, describe it in the
bug report, and include a patch if you like.
