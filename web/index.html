VCCA: VCC for Android, a Tandy Color Computer 3 emulator.
Android port by Carlos A. Camacho.

VCC (Virtual Color Computer), copyright 2015 by Joseph Forgione. “Another classic computer canceled before it's time!”
VCC repository and release packages maintained by Bill Pierce and Ed Jaquay. Adapted to Visual Studio by Gary Coulbourne and Wes Gale. Hitachi 6309 port by Walter Zambotti. Getting started

VCCA emulates a Tandy Color Computer 3. It needs the CoCo 3's own ROM, which can't be included with the app.

  1. Copy coco3.rom (and disk11.rom for floppies) to your device.
  2. ☰ → Cartridge → System ROMs → Load… for each one.
  3. The CoCo starts at the OK prompt.

Everything you load (ROMs, disks, tapes, settings) stays on this device until you uninstall VCCA or clear its storage.

Loading programs

Load… and Run… work like XRoar's. Pick a file:

  • .bin: goes straight into memory. Load: type EXEC to start it. Run: starts it.
  • .dsk: goes into drive 0. Run types RUN"…" or LOADM"…":EXEC for the program on it.
  • .cas / .wav: goes into the tape deck and plays. Run types CLOAD (then RUN) or CLOADM:EXEC.
  • .rom / .ccc: a program pak in slot 1. The Multi-Pak switch moves to slot 1; set it back to slot 4 for Disk BASIC.
Save states, screenshots and video

Three different things:

  • Save state (Commands tab or ☰ → File → Save states) freezes the whole running machine: memory, CPU, cartridges. Load state puts you back at that exact moment, mid-game if you like. Disks and tapes are not part of it, so loading a state never undoes what you saved to disk. A state only loads in the same VCCA version that saved it.
  • 📷 Screenshot saves a picture of the screen as a PNG.
  • ⏺ Video records the screen with sound until you tap ⏺ again (up to 3 minutes), as MP4 where the device supports it.
Keyboard
  • The on-screen keyboard is laid out like a CoCo 3's, as in XRoar.
  • SHIFT, CTRL and ALT are sticky by default: tap one, then the key. Change it in ☰ → Configuration → Keyboard.
  • A physical keyboard maps the PC way: Esc is BREAK, Home is CLEAR.
  • VCC's special keys work on a physical keyboard: F3/F4 overclock down/up, F5 soft reset (Shift+F5 hard reset), F6 RGB/composite, F7 pause, F8 throttle, F9 hard reset, F11 full screen.
  • ☰ → Edit → Type text into CoCo types a whole BASIC listing for you.
Joystick
  • ☰ → Configuration → Joystick sets each port, as in VCC: its input (on-screen stick or game controller, touch on screen, keyboard, or none) and its emulation type (Standard, Tandy Hi-Res Interface or CoCo Max). By default the on-screen stick is the right joystick.
  • In landscape the stick, screen and fire buttons sit side by side. ☰ → Configuration → Joystick → Joystick layout swaps the sides.
  • Springs back to center acts like a self-centering stick; Stays where released like a Tandy deluxe stick with centering off.
  • A Bluetooth or USB game controller also works.
  • For drawing programs, set the port's input to Touch on screen and its emulation type to the program's interface: your finger becomes the pen at full resolution.
  • Keyboard input uses the arrow keys and F1/F2 on a physical keyboard; those keys then stop reaching the CoCo.
Commands tab
  • The blue buttons type common BASIC commands. Ones that end in a quote or space wait for you to finish typing.
  • Slots 10–16 are yours: tap an empty slot to set it, hold a slot for a second to change it. Use | for ENTER, for example LOADM"GAME":EXEC|.
Floppy disks
  • Needs disk11.rom and the FD-502 controller, which is in Multi-Pak slot 4 by default.
  • ☰ → Cartridge → Floppy drives: Insert a .dsk, or make a New blank disk (it is formatted for you).
  • What the CoCo writes is kept. Save copies the disk image to your device.
  • Fast disk skips the drive's real timing.
Cassette tapes
  • The deck has PLAY, REC, STOP, REW (back to the start) and FWD (to the next program on the tape).
  • Loading: Insert a .cas or .wav, press PLAY, type CLOAD (BASIC) or CLOADM (machine code). Run… does all of that for you.
  • Saving: press REC (a blank tape goes in if the deck is empty), then type CSAVE"NAME" or CSAVEM"NAME",start,end,exec. Save tape… copies the tape to your device.
  • Fast loading runs at full speed while the motor is on. Choose Real time to hear the tape.
Hard drives (IDE)

A hard drive holds many floppies' worth of programs, numbered 0, 1, 2…, so you can switch between them without inserting anything.

  1. ☰ → Cartridge → System ROMs: load an HDB-DOS ROM built for the IDE interface (LBA). Set Disk controller ROM to HDB-DOS.
  2. ☰ → Cartridge → Multi-Pak: put IDE hard drive interface ($FF70) in a free slot (1–3). Keep the FD-502 in slot 4 and the switch on slot 4.
  3. ☰ → Cartridge → Hard drives: Create a master drive, or import an image.
  4. Hard reset.

In BASIC: DRIVE 5 then DIR lists virtual floppy 5; LOADM, RUN"…" and SAVE use it. DRIVE #1 switches to the slave drive; DRIVE OFF brings back the real floppy drives.

To fill virtual floppies, use Add .dsk files… on the drive, or SAVE to them from BASIC.

Printer (BitBanger)
  • ☰ → Configuration → BitBanger: Start capture, then print from the CoCo, for example LLIST or PRINT#-2,"HELLO".
  • Show printout displays it; Save printout… saves it as a text file.
  • Add LF to CR starts a new line after each carriage return, which most text viewers need.
Cartridges and sound
  • The Multi-Pak has four slots. The switch chooses which slot's ROM the CoCo starts from; games choose a sound cartridge's slot themselves.
  • A game's “GMC slot 2” means Multi-Pak slot 2 here.
  • A sound cartridge must be in the Multi-Pak for a game to be heard through it. Selecting the Orchestra-90 or a GMC slot with nothing there is silent, as on a real CoCo.
  • For disk games with GMC sound, use “Game Master Cartridge, sound only (disk games)”. A GMC game on cartridge needs its ROM.
  • The Stereo Composer and the IDE interface at $FF70 share addresses; use one or the other.
  • Cartridge changes take effect on the next hard reset.
Display
  • Picture: Full shows the whole border, Title a thin one, Zoomed none.
  • Scan lines darken the gaps between the CoCo's lines, drawn at your screen's own resolution so they stay even.
  • Monitor: RGB as on a CM-8 monitor, or Composite as on a TV.
ROMs
  • coco3.rom (required): the CoCo 3's BASIC. A 32,770-byte copy with a 2-byte header is fine.
  • disk11.rom: Disk Extended Color BASIC, for floppies.
  • HDB-DOS: for IDE hard drives.
  • Speech/Sound Pak: pic-7040-510.bin and sp0256-al2.bin.
  • Optional: orch90.rom (Orchestra-90 music program), psg_firmware_v1.bin (CoCo PSG menu).

If you use VCC on Windows, these are in its folder. They are copyrighted, so VCCA can't include them.

Troubleshooting

Still stuck? Report a bug: it opens a form on GitHub with your VCCA version and device already filled in.

  • Black screen, nothing happens: load coco3.rom.
  • No DISK in the startup message: load disk11.rom and keep the FD-502 in slot 4 with the switch on slot 4.
  • A game's sound option is silent: put that cartridge in the Multi-Pak, then hard reset.
  • A key on a physical keyboard does nothing: open ☰ → Configuration → Keyboard and press it. The key test there shows what VCCA receives; put that line in a bug report.
  • A save state won't load: it came from a different VCCA version.
  • A tape won't load: try Real time; a .wav made by converting a .cas may lack the silent gaps BASIC needs between blocks.
